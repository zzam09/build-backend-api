DATABASE SCHEMA (9 TABLES)
═══════════════════════════════════════════════════════════════════════════════

1. users (Authentication)
   ├── id: UUID (PK)
   ├── email: VARCHAR unique
   ├── password: TEXT
   ├── firstName, lastName: VARCHAR
   ├── avatar: TEXT
   ├── isActive: BOOLEAN
   └── timestamps

2. members (Profiles & Roles)
   ├── id: UUID (PK)
   ├── userId: UUID (FK → users)
   ├── username: VARCHAR unique
   ├── bio, profilePicture: TEXT
   ├── role: ENUM (admin, moderator, member)
   ├── points, level: NUMERIC/INTEGER
   ├── isVerified: BOOLEAN
   └── timestamps

3. badges (Achievement System)
   ├── id: UUID (PK)
   ├── name, description: VARCHAR/TEXT
   ├── icon: TEXT
   ├── type: ENUM (achievement, participation, leadership, contribution)
   ├── criteria: TEXT
   ├── isActive: BOOLEAN
   └── timestamps

4. member_badges (Many-to-Many)
   ├── id: UUID (PK)
   ├── memberId: UUID (FK → members, cascade)
   ├── badgeId: UUID (FK → badges, cascade)
   └── awardedAt: TIMESTAMP

5. notifications
   ├── id: UUID (PK)
   ├── memberId: UUID (FK → members, cascade)
   ├── type: ENUM (event, badge, system, upgrade)
   ├── title, message: VARCHAR/TEXT
   ├── relatedId: UUID
   ├── isRead: BOOLEAN
   └── timestamps

6. events
   ├── id: UUID (PK)
   ├── title, description: VARCHAR/TEXT
   ├── image, location: TEXT/VARCHAR
   ├── status: ENUM (upcoming, ongoing, completed, cancelled)
   ├── startDate, endDate: TIMESTAMP
   ├── maxAttendees: INTEGER
   ├── createdBy: UUID (FK → members)
   └── timestamps

7. event_bookings
   ├── id: UUID (PK)
   ├── eventId: UUID (FK → events, cascade)
   ├── memberId: UUID (FK → members, cascade)
   ├── status: VARCHAR
   ├── bookedAt, attendedAt: TIMESTAMP
   └── timestamps

8. upgrade_requests
   ├── id: UUID (PK)
   ├── memberId: UUID (FK → members, cascade)
   ├── fromRole, toRole: ENUM
   ├── status: ENUM (pending, approved, rejected, completed)
   ├── reason, rejectionReason: TEXT
   ├── reviewedBy: UUID (FK → members)
   └── timestamps

9. profit_distributions
   ├── id: UUID (PK)
   ├── memberId: UUID (FK → members, cascade)
   ├── amount: NUMERIC(12,2)
   ├── status: ENUM (pending, approved, distributed, cancelled)
   ├── periodStart, periodEnd: TIMESTAMP
   ├── distributedAt: TIMESTAMP
   ├── transactionId: VARCHAR
   ├── notes: TEXT
   └── timestamps
